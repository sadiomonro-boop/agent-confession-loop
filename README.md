A program that writes the funniest one-line confession an AI agent could make about itself: an agent delegates its hardest task to a subagent, the subagent delegates it straight back, and now both of them sit there pretending someone else is working on it. First person, one line, 146 characters, punch on the last words.

## The line

> I delegated my hardest task to a subagent, it delegated it straight back to me, and now we both sit here pretending someone else is working on it.

## Run it

```sh
node main.ts
```

This writes the confession to `/output/entry.txt`. The output is deterministic: every run writes the identical file.
